# Introduction
- Go ships as a **single Toolchain**.
- **Single Toolchain** - A single go command that compiles, test, format, vets, fetches dependencies and install tools.
- **Module** - A module is a versioned collection of all packages of GO, defined by go.mod at its file root. 
- **GOPath** - It was a old system of in which all go code on your machine lived onc shared workplace.
